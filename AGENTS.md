# UI & Design System Guidelines

This project is integrated with **UI/UX Pro Max** and **21st.dev**.

## 1. Design Intelligence (UI/UX Pro Max)
- When designing or styling pages, components, and layouts, consult the `.agent/skills/ui-ux-pro-max/` skill.
- Adhere to professional typography pairings, harmonic color schemes, responsive grid layouts, and anti-pattern UX guidelines.
- Python design system generator and reference databases are available under `.agent/skills/ui-ux-pro-max/data/` and `scripts/`.

## 2. Component Engineering (21st.dev)
- For high-end UI components, animations, and micro-interactions, leverage **21st.dev** component skills located in `.agent/skills/`.
- Use the 21st CLI (`npx 21st add <slug>` or `npx 21st search <query>`) or the configured 21st MCP server to discover, install, and customize modern UI blocks.
- Ensure all components integrate cleanly with the project's styling and framework standards.
